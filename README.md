### Hello, I'm justspawnzz 👋

I build mobile apps with Flutter and React Native, mostly products that need to work reliably offline and sync when they can. I spend a lot of time on interaction details — gesture handling, motion, making transitions feel physical rather than decorative. My stack is Dart and TypeScript on the client side, Firebase on the backend, and I keep things simple past that.

#### What I'm up to

- 🔭 Building an offline-first task app with conflict-free sync in Flutter.
- 🎯 This year's goal: ship something every month
